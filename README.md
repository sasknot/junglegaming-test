# Jungle Gaming NFT Marketplace — Bootstrap

Este repositório foi inicializado como um bootstrap de frontend em React + TypeScript para o desafio de marketplace de NFTs descrito em `INSTRUCTIONS.md`.

## Visão geral

- Roteamento inicial com páginas placeholder para:
  - Início
  - Detalhes do NFT
  - Carrinho de NFTs
  - Pagamento
  - Confirmação de Pedido
  - Login
  - Cadastro
  - Perfil
  - Carteiras
- Stack base preparada com React, TypeScript, Vite, Tailwind CSS, TanStack Query e TanStack Router.
- Estrutura pronta para expansão com mocks, APIs, autenticação e testes.

## Stack inicial

- React
- TypeScript
- Vite
- Tailwind CSS
- TanStack Router
- TanStack Query
- Axios

## Observações

- Este bootstrap não implementa o layout do Figma nem os fluxos completos da aplicação.
- As telas foram mantidas como placeholders, com estrutura visual e navegação funcionando para servir como ponto de partida do projeto real.
